## Password Reset

Users can reset their password by navigating to Settings > Security > Reset Password. 
Upon clicking "Reset Password", a confirmation email will be sent to the user's registered 
email address within 5 minutes. The reset link in the email is valid for 24 hours.

If the user does not receive the email, they should check their spam folder first. 
If it still doesn't arrive, they can contact support to manually trigger a reset from 
the admin panel.
